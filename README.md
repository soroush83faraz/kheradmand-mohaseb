# خردمند محاسب ارقام — وب‌سایت مؤسسه حسابرسی

[![پیش‌نمایش سایت خردمند محاسب ارقام](assets/demo.gif)](https://soroush83faraz.github.io/kheradmand-mohaseb/)

## 🌐 [مشاهده سایت — کلیک کنید](https://soroush83faraz.github.io/kheradmand-mohaseb/)

سایت معرفی مؤسسه حسابرسی و خدمات مالی «خردمند محاسب ارقام» — ساخته‌شده با Next.js (خروجی استاتیک).

نسخه ویدیویی پیش‌نمایش: [`assets/demo.mp4`](assets/demo.mp4)

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

## ساخت خروجی استاتیک

```bash
npm run build
```

خروجی در پوشه `out/` ساخته می‌شود. برای GitHub Pages متغیر `NEXT_PUBLIC_BASE_PATH=/kheradmand-mohaseb` هنگام build تنظیم می‌شود (در ورک‌فلو انجام شده). برای دامنه اختصاصی این متغیر را خالی بگذارید.

## ساختار

- `app/` — صفحات (App Router): خانه، خدمات، فرایند کار، مقالات، پرسش‌های متداول، درباره ما، تماس
- `lib/` — محتوای سایت (خدمات، مقالات، سوالات متداول، اطلاعات تماس)
- `components/` — هدر (با تم روز/شب)، فوتر، فرم تماس و…

## نکته‌های محتوایی

- اطلاعات تماس، آدرس و آمار در `lib/site.js` و صفحه اصلی **موقت** هستند و باید با اطلاعات واقعی مؤسسه جایگزین شوند.
- مقالات در `lib/posts.js` نگهداری می‌شوند؛ برای افزودن مقاله جدید یک آیتم به آرایه اضافه کنید.

## دیپلوی

هر push به شاخه `main` به‌صورت خودکار روی GitHub Pages منتشر می‌شود (ورک‌فلو `deploy.yml`).
